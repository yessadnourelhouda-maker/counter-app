🔢 Passenger Counter App
A simple and interactive passenger counter application built using HTML, CSS, and JavaScript.

📌 About the Project
This project is a passenger counter designed to keep track of the number of people entering a place. Users can increment the counter and save the current count to keep a record of previous entries.
The goal of this project is to practice JavaScript fundamentals, DOM manipulation, and interactive web development.

✨ Features
    Increment the passenger count.
    Save the current count.
    Display previous entries.
    Interactive buttons.
    Simple and user-friendly interface.
